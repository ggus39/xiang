博客写作模板与说明
====================

这个文件是给 F:\myblog 这个 Hugo 博客用的写作参考。
真正发布到网站的文章文件，要放在 content 下面对应的栏目文件夹里，文件后缀用 .md。


一、文章应该放在哪个文件夹
------------------------

content/thoughts/   -> 想法
content/posts/      -> 记录
content/habits/     -> 习惯
content/Excerpt/    -> 摘句
content/journals/   -> 周月记

records 文件夹现在不用了，之前已经合并进 posts。


二、一篇文章的基础模板
--------------------

复制下面这一段，新建一个 .md 文件后粘贴进去：

---
title: "这里写文章标题"
date: 2026-06-28T12:00:00+08:00
draft: false
---

这里写第一段正文。网页默认会首行缩进两个中文字符。

这里写第二段正文。想要分成下一段，就中间空一行。


三、时间戳怎么写
---------------

格式：

2026-06-28T12:00:00+08:00

含义：

2026-06-28  -> 日期，2026 年 6 月 28 日
T           -> 日期和时间中间的固定分隔符
12:00:00    -> 时间，12 点 00 分 00 秒
+08:00      -> 中国时区，固定这样写就行

常用例子：

早上八点：
2026-06-28T08:00:00+08:00

晚上十点：
2026-06-28T22:00:00+08:00

如果只是记录当天，不确定具体时间，可以统一写：
2026-06-28T12:00:00+08:00


四、大标题、小标题怎么写
----------------------

Markdown 里用 # 表示标题。

# 一级大标题

## 二级标题

### 小标题

#### 更小的小标题

建议：

1. 文章最上面的 title 已经是页面大标题，正文里通常从 ## 或 ### 开始就够了。
2. 日记、想法类文章可以少用标题，直接分段写。
3. 周记、月记比较长，可以用小标题整理。

周记示例：

## 这一周做了什么

这里写内容。

## 这一周的状态

这里写内容。

## 下周想试试

这里写内容。


五、换行和分段怎么写
------------------

最推荐的写法：想要新段落，就空一行。

正确示例：

今天出去走了一圈，感觉状态好了一点。

晚上回来之后，还是想把节奏慢慢找回来。

网页显示时：
- 第一段首行缩进两个字
- 第二段首行也缩进两个字
- 两段之间会有自然间距

不推荐只按一次 Enter 来表示新段落：

今天出去走了一圈，感觉状态好了一点。
晚上回来之后，还是想把节奏慢慢找回来。

这种在 Markdown 里更像同一段中的换行，不如空一行清楚。

简单记法：

下一段 = 空一行
普通换行 = 尽量少用


六、首行缩进规则
---------------

网站现在默认：文章正文里的普通段落会首行缩进两个中文字符。

比如你写：

今天有点累，但还是想记下来。

网页上会显示成：

　　今天有点累，但还是想记下来。

注意：你在 .md 文件里不用手动敲两个空格，网页会自动缩进。


七、某一篇不想首行缩进怎么办
--------------------------

在文章开头加：

noIndent: true

完整示例：

---
title: "这篇不缩进"
date: 2026-06-28T12:00:00+08:00
draft: false
noIndent: true
---

这篇文章的正文不会首行缩进。
适合摘句、短诗、清单、格式比较特殊的文章。


八、列表怎么写
-------------

无序列表：

- 第一项
- 第二项
- 第三项

有序列表：

1. 第一件事
2. 第二件事
3. 第三件事

列表里的内容不会被强行首行缩进。


九、引用怎么写
-------------

用 > 表示引用：

> 这里是一句摘录。
> 可以继续写第二行。

适合放播客、书、文章里摘出来的句子。

如果一整篇都是摘句，也可以在开头加 noIndent: true。


十、加粗、斜体、分隔线
--------------------

加粗：

**这里会加粗**

斜体：

*这里是斜体*

分隔线：

---

注意：文章最开头的 --- 是 front matter 的边界，不是分隔线。正文里的 --- 才是分隔线。


十一、代码或原样文本怎么写
------------------------

少量行内代码：

`git push`

多行代码或原样文本：

```text
这里面的内容会按原样显示。
不会自动首行缩进。
```


十二、文件名怎么起
----------------

推荐用日期：

2026.6.28.md
2026.6.28-weekly.md
2026.6.monthly.md

不要用太复杂的中文文件名，虽然可以用，但以后链接和管理会更麻烦。

十四、手机写作入口
----------------

手机打开：

https://ggus39.github.io/xiang/write/

流程：

1. 选择板块
2. 填标题
3. 写正文
4. 点复制 Markdown
5. 点打开 GitHub
6. 新建对应的 .md 文件
7. 粘贴并提交


十五、电脑本地发布流程
--------------------

在 PowerShell 里进入：

F:\myblog

然后执行：

.\hugo.exe --cleanDestinationDir
git add .
git commit -m "更新博客"
git push

意思是：

1. Hugo 重新生成 public 网站文件
2. git add . 把变化加入暂存区
3. git commit 形成一次提交
4. git push 推送到 GitHub


十六、最重要的三句话
------------------

1. 写文章，改 content 里面的 .md。
2. 想分段，中间空一行。
3. 不想缩进，在文章开头加 noIndent: true。
